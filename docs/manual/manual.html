CHAPTER 011 这是什么

AI Knowledge Navigator 把「硬核 PDF」变成可点击的知识图谱：先看结构，再点开知识点读它的说明 （是什么、先修什么、为什么重要、怎么自测）；要核对细节时一键跳回 PDF 原文。你不必从第一页读到最后一页。

1.1 它替你解决的三个问题

问题这个软件怎么做
论文太长，不知道先读哪 用 AI 抽出跨章节的核心概念，从左到右按依赖方向排列成脑图；节点是椭圆（宽 = 高 × 2.2，两行内截断，文字不出框），大小 = 关联程度（连边越多越大，与字数无关），颜色深浅 = 掌握难度（越深越难），红 = 未掌握、绿 = 已掌握（点节点内圆点切换）。有向边标出「依赖/触发/属于」等关系。
概念看不懂，来回翻 PDF 点知识点弹出学习对话框：先用一段知识点描述讲清这个概念是什么，再给先修、精细加工（类比 / 对比 / 常见误解）与自测题；有图表时附 caption 与区域截图；要核对原文一键跳回 PDF 位置。
想法记不住，笔记和原文脱节 在 PDF 原文上划选就能标注，标注与图谱知识点是**同一条记录**；AI 回答可带引注发送到笔记，最终一键导出 Markdown。

1.2 它不做什么

  • 不把 PDF 上传到云端。文件、图谱、标注全部存在本机浏览器 IndexedDB。
  • 不假装知道。没有 API Key 时，AI 功能会用本地 Mock 上游跑通链路并明确标注「Mock 上游」，不冒充真实模型结论。
  • 不编造页码。AI 给的引注会回原文核对，核对不上就显示「无直接出处」。

CHAPTER 022 安装与运行

2.1 你需要什么

项目要求
Node.js≥ 20 LTS（本项目在 v24 上验证）
pnpm本仓库使用 pnpm workspace
浏览器Chrome / Edge 等现代浏览器（需要 IndexedDB 与 module worker）
DeepSeek API Key可选。不填也能用 Mock 模式体验全流程

2.2 两种运行模式

模式 A：零配置（Mock 上游）—— 推荐第一次使用

cd ai-knowledge-navigator
pnpm install            # 首次需要；已装过可跳过
LLM_MOCK=1 pnpm dev     # 同时启动前端(5173)与代理(8787)

浏览器打开 http://localhost:5173。界面右上角会显示 Mock 上游 角标，表示 AI 结果是本地模拟的，用于跑通流程。

模式 B：真实 AI

cp .env.example server/.env.local      # 填入 DEEPSEEK_API_KEY
pnpm dev                               # 不加 LLM_MOCK
密钥边界：API Key 只存在于 server/.env.local（已在 .gitignore 中）， 前端代码、浏览器存储与构建产物里都不会出现；所有 LLM 请求走同源 /api/llm/* 代理。

2.3 端口与脚本

命令作用
pnpm dev并行启动前端 5173 与 Hono 代理 8787
pnpm -r typecheck全量 TypeScript 类型检查
pnpm -r test单元测试（118 个用例）
pnpm -r build生产构建
node scripts/step6-learning-dialog.mjs学习对话框全链路验收（需先 LLM_MOCK=1 pnpm dev）

CHAPTER 033 界面导览

3.1 三栏各管什么

  • 左栏 · 文档目录：来自 PDF 自身的书签（outline），只用于跳页与圈定章节范围；每条目录带层级编号（1 / 1.1 / 3.1.1），一级条目标「章」并加粗；书签标题本身已带编号时不会重复显示；章节很多时目录区可独立滚动（不会把页面撑开）。目录条目不是知识点：图谱里既不会出现「章节节点」，也不会把它当成关联端点（否则它会和所有知识点都连上，把真正的语义关系稀释掉）。图谱切到「章节模式」后可以对该章节做 🚀 AI 开启拆解。PDF 没有书签时显示明确空态，不伪造目录。
  • 中栏 · 知识图谱（默认）/ PDF 阅读：默认进图谱。PDF 阅读器不会卸载，切 Tab 不重新解析、不丢滚动位置。
  • 右栏 · AI 伴读 / 笔记：两个 Tab 切换，宽度与中栏共享同一列拖拽规则。

3.2 顶栏

  • 打开 PDF：选择本地文件，解析后入 IndexedDB（不会上传）。
  • 重置栏宽：三栏宽度恢复默认（左 260 / 右 380）。
  • 代理状态点：绿=后端代理正常，红=后端未启动；悬停可看服务版本与是否配置了 Key。
  • 左/右宽度读数：仅开发模式显示，方便调布局。

CHAPTER 044 第一次学习：五步走

第 1 步：打开一份 PDF

点顶栏 打开 PDF，选文件。左栏会立刻出现 PDF 的书签目录（如果这份 PDF 有书签）。

本手册自身就是一份 PDF，你可以用它练习：点 打开 PDF 选中本文件， 左栏会出现 1–10 章与附录的书签。

第 2 步：让 AI 抽取图谱

中栏切到 知识图谱，点右上角 ⛏ AI 抽取全局图谱。流程是：切块 → 逐块抽取 → 实体合并 → **先搭总纲再挂细节**（汇总阶段只读每个知识点的摘要与候选关系，先识别 3–8 个总纲概念，其余按语义归属挂上去）。目录只用来切块与定位，不参与图的结构划分。所有中间结果按块缓存，重复抽取不会重复计费。

图谱分成两组，用顶部的 ① 全文档总览 / ② 章节拆解 切换。每个知识点还带一个 认知层级（L1 定位 / L2 连接 / L3 推断 / L4 组织 / L5 选择），展开「学习路径」会按「先学简单的、再学依赖它的」排好序。点路径里的条目只在图谱里高亮对应节点（其余节点与连线变暗），并把它平滑移到画布中心；不会弹出详情，想看详情请点图谱里的节点本身。

  • ① 全文档总览：全文档核心知识点，从左到右按依赖排布（左边是前置知识，右边建立在它之上），带箭头指向（3px 粗线 + 大箭头）；同一层节点多时会自动折成多列，不会堆成一根竖线。大小代表关联程度（连接的边越多越大，说明涉及面越广）；颜色深浅代表掌握难度（越深越难）；红/绿代表未掌握/已掌握。点节点内的圆点即可在红↔绿之间切换，尺寸与深浅不变。点任意节点后，不相关的节点与连线会一起变暗，只留下它的直接上下游。
  • ② 章节拆解：选中某一章后点 🚀 AI 开启拆解，得到更细的子图；每个节点直接锚定到原文核心点，点开就是该知识点的描述与「跳到 PDF 原文」。上方还有「章节速览」入口，点开是**可拖动、可关闭的浮窗**（不会挤压图谱）：它把这一章逐段总结（一个知识点一段，只讲内容、不给学习顺序建议）；正文里的知识点名称是可点关键词，点击即选中下方图谱里对应的节点（联动高亮，并自动移到画布中心）。学习路径清单在速览下方。
没有配置 Key？ 若看到「服务端未配置 DEEPSEEK_API_KEY（503）」：要么按 2.2 配置 Key， 要么用 LLM_MOCK=1 pnpm dev 启动以 Mock 上游体验流程。

第 3 步：点开一个知识点

点图谱里任意椭圆 → 弹出 学习对话框：标题与掌握状态、知识点描述（一段话讲清它是什么）、先修（学它之前必须先掌握什么）、精细加工（类比 / 对比 / 为什么重要 / 常见误解）、自测（先自己想，再展开答案要点），以及笔记与上下游。

对话框读的是「这个概念是什么」，不再堆两百字上下文。如果某个知识点还没有描述，对话框会显示 点击进一步分析：按需调一次模型补上描述、原文锚点、精细加工与自测题（不会重新生成整张图）。

第 4 步：跳回原文核对与标注

点对话框底部的 跳到 PDF 原文：切到 PDF Tab、滚到锚点页，并在原文句子下方画一条闪烁的黄色下划线（匹配不到时退化为整页闪一下并提示，不假装命中）。

在 PDF 正文里划选任意一句 → 弹出气泡 → 写批注（可留空）→ 保存。这条标注会：

  1. 写入本机 IndexedDB；
  2. 立刻在 PDF 同一位置显示为黄色高亮；
  3. 之后再从图谱打开该知识点，仍能一键跳回同一处原文。

第 5 步：继续往下学

对话框右下「前置依赖 / 后置影响」里的条目可以直接点，对话框会原地切换成相邻知识点——学习是顺着图谱走的，不用回 PDF 翻页。

CHAPTER 055 学习对话框详解

5.1 对话框里有什么

区域说明
标题与元信息知识点标题、认知层级、单元类型、重要度、掌握状态、来源与锚点页码。
知识点描述一段话讲清「它是什么、解决什么问题」（抽取给的 summary；按需分析后更完整），下方标出别名。
先修 / 精细加工 / 自测学它之前应先掌握的概念；类比、对比、为什么重要、常见误解；一道可展开答案的自测题。
图表该知识点附近出现 Figure N: / Table N: 之类 caption 时，附 caption 与按 caption 估算区域渲染出的 PNG，并可直接「在 PDF 查看」。图表/表格知识点即使模型只给了 caption、没给逐字引文，也能跳原文：按 caption 在该页定位并画下划线，定位不到就落到图表页并整页闪一下。
知识点笔记不需要划选，直接写下你对这个知识点的理解；存入独立的 notes 表。
继续学前置依赖 / 后置影响条目，点击原地切换知识点。
跳转底部「跳到 PDF 原文」：切到 PDF Tab、滚到锚点页、并临时高亮原文（约 2.6 秒）。

5.2 知识点描述从哪来

描述来自抽取阶段每个知识点的 summary（≤ 40 字，模型读原文写的）；点 点击进一步分析 会让模型读该知识点附近的原文， 重写一条更完整的描述（≤ 120 字），并补上先修、精细加工与自测题。图表占位节点没有摘要时，描述回落到图表的 caption。 描述的语言跟随右上角「输出语言」设置；引用的原文始终保留原样，不做翻译。

验证方法：打开一个只有标题的空节点 → 显示「点击进一步分析」→ 点一下 → 描述、先修与自测出现，图谱结构不变。

5.3 已知限制

  • 对话框不再展示原文摘抄（前后各 200 字的上下文）：要在原文里读细节，请点「跳到 PDF 原文」。
  • 描述长度有限：抽取阶段 ≤ 40 字，按需分析 ≤ 120 字；更细的内容用 AI 伴读或直接读原文。
  • 图表区域是按 caption 估算的（向上扩 35% 页高），复杂双栏排版可能框多或框少。
  • 划选标注在 PDF 侧完成（见 6.2）；知识点没有可定位的逐字引文时只能按页跳转，界面会写明「没有可定位的原文锚点」。

CHAPTER 066 PDF 阅读器

6.1 目录与跳页

左栏目录来自 PDF 书签，支持多级层级；点击条目会滚动到对应页并同步页码指示器。没有书签的 PDF 会显示空态（章节结构留给 AI 抽取补足）。

6.2 章节掌握度与书签

目录每行左侧的小圆点表示这一章掌握到哪了（统计依据：该章页码范围内的知识点，按标题去重；① 总览与 ② 章节拆解里勾过的都算）：

  • 实心绿圈：本章知识点全部已掌握；圆点与整行悬停都会提示「本章已全部掌握（m/n）」。
  • 半绿圈：掌握了一部分；悬停提示「已掌握 m/n」。
  • 灰色空心圈：还没开始，或一个都没掌握（本章没有知识点时也显示为空心）。

左栏底部有这三种状态的图例与「已掌握 m/n」总计。子章节会把自己和下级章节一起算，父章节的圆圈 = 整棵子树。

章节书签：点行尾的绸带书签图标（上边平、下边剪掉一个三角缺口）给这一章加书签，加好后变实心，再点一次取消。下次打开这份文档（含刷新页面自动恢复）会直接跳到最近钉住的那一章：中栏切到 PDF 并滚到该章首页，左栏顶部出现「已跳到书签：…（第 N 页）」提示，可点 × 关闭。书签存在本机 IndexedDB，换设备不会同步。

同一份 PDF 如果重新「打开 PDF」再选一次，会被当成一份新文档（现有行为），书签与掌握状态不会跟过去； 正常用法是关掉页面再打开，软件会自动恢复上次的文档。

6.3 高亮与备注

  1. 在 PDF 正文里用鼠标划选文字 → 弹出气泡 → 选择表情、写备注（可留空）→ 保存。
  2. 点击已有高亮 → 弹出编辑气泡：可改备注、改表情、删除。
  3. 气泡里还会显示「关联图谱节点」：若这段原文能匹配到某个知识点，给出「定位」按钮，一键跳到图谱并打开该知识点；匹配不到则明确提示未关联。

6.4 双向联动

从哪到哪效果
图谱节点 → PDF「跳到 PDF 原文」：切 Tab、滚到锚点页，并在**原文句子下方画一条闪烁的黄色下划线**（跨多行就每行一条）；匹配不到时才退化为「整页闪一下」并提示「已标出该页」，不会假装命中。
图表/表格节点 → PDF同样的「跳到 PDF 原文」，但目标是 caption：能逐字命中就在 caption 下画闪烁下划线，命中不到就退化为「整页闪一下」并提示「已标出该页」。
PDF 高亮 → 图谱点高亮气泡里的「定位」：切到图谱并打开该知识点的学习对话框。
PDF 选区 → 提问选中文字后，右栏输入框上方出现可删除的 context chip。

CHAPTER 077 AI 伴读

7.1 提问与上下文

右栏 AI 伴读 Tab 里提问。两种方式会自动注入上下文：

  • 在 PDF 里选中文本 → 生成「选中原文」chip；
  • 在图谱里点节点 → 生成「图谱节点」chip。

chip 可以随时点 × 删除；发送后会随问题一起带给模型，发完自动清空。

7.2 引注：为什么不担心编造页码

回答会带形如 [引用] 第6页：「原文片段」 的引注。软件不会直接相信这些引注，而是拿回 PDF 文本层逐条核对：

核对结果界面表现
原文能对上绿色条目：第 N 页 +「原文」，其中页码用的是真实命中页（模型写错也会被纠正）。
对不上黄色条目：无直接出处，另附一行灰色的「模型声称：…」，页码不显示。
模型没给引注仍生成一条「无直接出处」条目，不会出现空白。

每条回答下方有 发送到总结笔记，会把这条回答（含引注）送进笔记面板待插入队列。

CHAPTER 088 笔记与 Markdown 导出

8.1 四类可插入内容

按钮来源
节点卡片当前在图谱里选中的知识点（标题 + 难度 + 掌握状态）。
原文高亮最近一条 PDF 高亮（原文 + 页码）。
AI 回答点了「发送到总结笔记」的回答，按钮上会显示待插入数量。
图谱截图当前知识图谱视图的 PNG（需先切到图谱视图）。

8.2 导出 Markdown（P0）

点 导出 .md：先展示真实序列化结果的预览，再点「下载 .md」。降级规则是固定的：

笔记内容导出形态
普通段落 / 标题 / 列表 / 代码块标准 Markdown
节点卡片> **【节点】标题** + 重要度星级与掌握状态
原文高亮引用块 + — p.页码
AI 回答引用块 + 出处：p.N「原文」 或 出处：无直接出处
截图默认内联 base64；单图 > 1.5MB 或全篇 > 8MB 时降级为 akn-assets/image-N.png 占位并在文首提示

8.3 同步（P1，仅占位）

Obsidian / Notion / 飞书三个目标目前只有接口与配置校验，点了会明确返回「P1 未实现」，不会发真实请求。

CHAPTER 099 数据、密钥与隐私

9.1 数据存在哪

内容位置
PDF 原文件、目录、高亮、图谱、笔记、抽取缓存浏览器 IndexedDB（库名 ai-knowledge-navigator）
界面偏好（Tab、栏宽、导出选项）localStorage（键 akn.ui）
API Key仅 server/.env.local，不进浏览器

9.2 怎么清空

浏览器开发者工具 → Application → Storage → Clear site data，或换一个浏览器配置文件。清空后刷新页面即可重新开始。

换浏览器 = 换数据。IndexedDB 与 localStorage 都是按「浏览器 + 站点」隔离的， 在 A 浏览器里的标注不会出现在 B 浏览器里。需要迁移请用笔记导出 Markdown。

CHAPTER 1010 常见问题

Q1：没有 API Key 能用到什么程度？

除了「AI 抽取图谱 / 章节拆解 / 伴读提问」这三处需要上游，其余全部可用：打开 PDF、目录跳页、划选高亮与备注、图谱渲染与交互、缓存、笔记、Markdown 导出。用 LLM_MOCK=1 pnpm dev 时这三处也能跑，但结果标注为 Mock。

Q2：点「AI 抽取全局图谱」报 503？

服务端没有检测到 DEEPSEEK_API_KEY。两种解法：配置 Key 后普通 pnpm dev；或改用 Mock 模式启动。

Q3：抽取失败了怎么办？

看图谱上方的红色错误条。常见原因：模型输出不是合法 JSON（软件会自动做一次「只修格式」的重试，仍失败则该块标记 failed）、网络超时、Key 无效。失败不会产生假节点，重试即可。

Q4：重复点抽取会不会重复花钱？

不会。每个块的结果按「文档 + 块哈希 + prompt 版本」缓存，重复抽取直接读缓存；改 prompt 版本才会失效。

Q5：图表摘抄里的图片黑掉/框错位置？

图表区域是按 caption 位置估算的（上扩 35% 页高），没有做图形语义识别。位置不准时可以点「在 PDF 查看」看原页。

Q6：对话框里不能删标注？

当前版本请到 PDF 侧点击该高亮的气泡删除。这是已知限制，下一步会补对话框内的编辑/删除。

Q7：为什么我的 PDF 目录是空的？

这份 PDF 本身没有书签。软件不做伪造目录；章节结构可以在抽取图谱后由 AI 补足。

Q8：三栏挤在一起了？

点顶栏「重置栏宽」；或拖拽分隔条重新分配。窗口很窄时中间阅读区有 360px 最小宽度保护。

APPENDIX B附录 B：术语表

术语含义
知识点（节点）AI 从 PDF 抽出的一个概念，带重要度 1–5、掌握状态与原文锚点。
重要度1=细节术语，5=全文级核心概念。决定节点大小与红/绿深浅。
掌握状态未掌握=红系，已掌握=绿系；切换只换色系，不改尺寸。
锚点（anchor）知识点对应的原文位置：页码 + 逐字引文 quote + 可选矩形。
知识点描述用一段话讲清该知识点「是什么、解决什么问题」的文字（抽取的 summary，按需分析可加长）。
引注（citation）AI 回答附带的出处，必须回原文核对；核对不上就是「无直接出处」。
块（chunk）抽取时按章节对齐切出的文本单元，缓存以它为粒度。
Mock 上游本地模拟的 LLM 服务，用于无 Key 时验证链路；界面会明确标注。
读完这份手册，你已经会用了。剩下的是它替你做的那些琐事：抽概念、对齐原文、核对引注、把标注同时留在两处。 祝你读得慢一点、想得多一点。
